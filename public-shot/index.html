Search widget for static sites

Hawk

Pagefind-backed command-palette search you can actually make match your site — theme it, tab it, pin it, or leave every default exactly as it ships.

Get started View source
$ npm install @staticcanvas/hawk

Features

Pagefind-backed

Chunked, lazily-loaded index with typo tolerance, scaling past a hand-rolled in-browser scorer — hawk owns the UI, Pagefind owns ranking.

Tabs, curated or auto-derived

Auto-derived category pills by default, explicit tabs with full Pagefind filter power, a sort-based listing tab (e.g. "Recently updated"), or a tab list loaded from a JSON file.

Themeable to the token

Every color, font, and scrollbar is a --hawk-* custom property. Ship a CSS file, or a few tokens inline with theme.tokens — no fork required.

Real page previews

The preview pane fetches and renders the actual matched page — headings, code blocks, tables — not a short excerpt. A page-level match can break into a scannable section outline instead of a full dump.

Modal reveal animations

5 built-in open/close animations (fade, scale-fade, slide-down, blur-zoom, spring), a custom one of your own, or none — always instant under prefers-reduced-motion.

Fit, medium, or compact

An in-modal density switcher, persisted per visitor, on top of scale/position/columns layout params.

Keyboard-first

A real focus trap, two-pane Tab navigation, arrow-key scrolling, Ctrl/Cmd+K — accessible by default, not bolted on after the fact.

Pins and inline filters

Visitors pin results for later, or type category:Guides directly into the search box — Pagefind's own filtering, exposed as a typed shortcut.

Zero-config to start

One constructor call, a Pagefind index, and a trigger element get you a working search. Typeflow's typewriter and a built-in trigger button are opt-in.
