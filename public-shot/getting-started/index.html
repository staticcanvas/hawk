Guide

Getting started

Install hawk, index a built site with Pagefind, and mount the search modal.

Install

npm install @staticcanvas/hawk
npm install --save-dev pagefind

pagefind is a real dependency — hawk has nothing to search without an index, so it’s installed automatically. @staticcanvas/typeflow is an optional peer dependency, only needed if you use the typeflow theme/animation driver instead of the built-in unstyled/instant ones.

Build an index

Mark your page’s main content region with data-pagefind-body, and mark chrome you don’t want indexed (nav, header, footer) with data-pagefind-ignore — see Pagefind setup for why this matters. Then, against your already-built site: 

npx pagefind --site dist

That writes a pagefind/ folder into dist/ containing the index and a small runtime.

Mount hawk

import { HawkSearch } from '@staticcanvas/hawk';
import '@staticcanvas/hawk/theme-typeflow/css';
import { HawkThemeTypeflow } from '@staticcanvas/hawk/theme-typeflow';

HawkSearch.registerTheme('typeflow', HawkThemeTypeflow);

const search = new HawkSearch({
  index: '/pagefind/',
  triggerSelector: '[data-search-trigger]',
  theme: 'typeflow',
});

Any element matching triggerSelector opens the modal — hawk builds its own DOM, so no other markup is required. Ctrl/Cmd+K and / open it by default (configurable via hotkeys).

Browser / CDN

Hawk ships UMD builds too, for script-tag usage without a bundler:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@staticcanvas/hawk@latest/dist/hawk.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@staticcanvas/hawk@latest/dist/hawk-theme-typeflow.css">
<script src="https://cdn.jsdelivr.net/npm/@staticcanvas/hawk@latest/dist/hawk.js"></script>
<script src="https://cdn.jsdelivr.net/npm/@staticcanvas/hawk@latest/dist/hawk-theme-typeflow.js"></script>
<script>
  new Hawk({ index: '/pagefind/' }); // hawk-theme-typeflow.js already self-registered as 'typeflow'
</script>

Loaded in this order, hawk-theme-typeflow.js registers itself against window.Hawk automatically — no Hawk.registerTheme(...) call needed. Add typeflow.js and hawk-animation-typeflow.js (in that order, both before the final <script>) for the typewriter animation driver too, which self-registers the same way once it sees both window.Hawk and window.TypeFlow.
