# Editor integrations

Reserved. Hawk has no custom syntax or DSL of its own (unlike lume's "lirl" tooltip syntax,
which is why lume has `editors/neovim`, `editors/vscode-lirl`, `editors/zed-lirl`) — there is
nothing here yet to write an editor plugin for. This directory exists so the layout matches the
org's package template; it stays empty until there's a real integration to add.
