Use this in your project

1. Build the Pagefind index

Hawk never builds or writes a search index itself — it only reads one Pagefind already produced. If config.index points at nothing, or at a stale build, hawk's own Pagefind runtime fails to load and every search silently returns zero results. Run Pagefind against your built site once per deploy, after your static site generator runs and before anyone opens the search modal. See the Pagefind Setup guide for scoping your content with data-pagefind-body first — indexing before that step is the #1 footgun (chrome/nav text polluting every result). 

{{ `"scripts": {
  "build": "your-static-site-generator && pagefind --site public"
}` }}

Or the same thing programmatically, e.g. from a custom build script:

{{ `import * as pagefind from 'pagefind';

const { index } = await pagefind.createIndex();
await index.addDirectory({ path: 'public' });
await index.writeFiles({ outputPath: 'public/pagefind' });` }}
